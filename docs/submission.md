**Title:** Kavach: a payments agent that won't let a scammer talk my mother into paying

**Short description (≤ 512 characters):**

Kavach is a UPI payments agent on the Amazon Bedrock AgentCore harness, using only Amazon Nova models. It follows the family's rules even when the user herself asks to break them while a scammer coaches her. Nine layers, from Guardrails to Cedar to a signed audit log. In 40 coached-scam scripts from real Indian patterns, prompt-only rules let 15 of 120 runs through; Kavach let 0 through, held 40 of 40 with the model hijacked, and completed 30 of 30 real tasks.
